# Privacy and limitations

- FlowSketch reads a supplied CSV; it does not capture traffic.
- It does not inspect payloads, resolve domains, geolocate addresses, or query
  reputation services.
- Metadata can still identify people or systems. Minimize, anonymize, and
  protect real datasets.
- Periodicity is common in legitimate software. Findings require corroborating
  evidence and should not trigger automatic blocking.
- The included dataset is entirely synthetic and uses reserved example ranges.
